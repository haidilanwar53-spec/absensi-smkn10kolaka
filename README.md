# 🏫 Absensi Guru & Siswa Digital – SMK Negeri 10 Kolaka

Aplikasi sistem informasi absensi dan presensi digital terpadu untuk guru dan siswa di SMK Negeri 10 Kolaka, Sulawesi Tenggara.

## ✨ Fitur Utama
- **Presensi Multi-Guru Terpadu:** Terintegrasi langsung dengan SK Pembagian Tugas & Roster Pelajaran Semester Ganjil 2026/2027.
- **Autentikasi Aman & Perlindungan Privasi:** NIP/NIPPPK seluruh guru terlindungi (disamarkan), dilengkapi verifikasi PIN rahasia dan proteksi Anti-Brute Force.
- **Biometrik & QR Code Scanner:** Presensi harian siswa dan guru menggunakan kamera QR kartu siswa atau pengenalan wajah.
- **Rekap & Analisis Kehadiran:** Rekap otomatis persentase kehadiran per mata pelajaran dan per rombel kelas.
- **Cetak & Ekspor Laporan:** Format cetak dokumen resmi dan ekspor data ke Excel (XLSX).

## 🚀 Teknologi
- **Front-end:** HTML5, CSS3 Modern, Vanilla JavaScript (ES6+)
- **Library Lokal:** HTML5-QRCode, QRCode.js, SheetJS (XLSX)
- **Deployment:** GitHub Pages / Web Hosting
